I made this project to make sports news more accesable to all those who want quick news in a fast manner. In this app you can see general neews about all the different types of sports or search specific teams you support. Anything your heart desires to learn about your favorite sports team you can in this app. Get on and Search away!


This project is a Flask-based sports news app. The main app file defines the routes for the homepage, a saved-favorites page, and each article detail page. When a user selects a sport like NFL or NBA, the app looks up a sport-specific query, fetches recent articles from the news API, filters out irrelevant content, and renders the results in HTML using templates. The homepage also supports search by team name, which helps match queries like “Lakers” or “Chiefs” to the right league rather than mixing different sports together.

The actual API logic lives in the news helper file. It sends requests to the external news service, receives JSON, normalizes the response into a consistent article format, and returns only the fields the app needs: title, URL, description, source, image, and published date. Back in the main app, a relevance filter checks whether the article text matches the selected sport or searched team, boosting strong matches and removing generic or unrelated articles. This is the main fix that prevents college football or basketball articles from showing up in the wrong sport feeds.

Favorites are stored in SQLite using a small database layer. Each article has a URL as its identifier, so the app can check whether it was already saved, save a new favorite, and remove one later. This keeps the feature simple and fast without introducing a heavy database framework. The frontend is mostly server-rendered HTML templates styled with custom CSS, with a little JavaScript only for small UI interactions and validation.

Overall, the app is a lightweight full-stack project: Flask handles routing and logic, the API client fetches live sports headlines, SQLite stores the saved articles, and templates/CSS provide the visual experience. The design is intentionally clear and modular so it is easy to extend with more leagues, team mappings, or a richer search experience later.
